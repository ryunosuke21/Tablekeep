---
title: Schedule sessions
description: Set a recurring game night and adjust individual sessions without rebuilding the schedule.
---

DMs manage the schedule from **Campaign → Settings → Schedule**. The campaign overview and dashboard show the next resolved session.

## Set the regular schedule

1. Choose the first date and start time.
2. Pick a repeat pattern: daily, weekly, monthly, or custom.
3. For a custom weekly pattern, choose the interval and weekdays.
4. Choose **Save schedule**.

Tablekeep uses the time zone reported by the DM's device and keeps the intended local meeting time through daylight-saving changes.

![The schedule editor with start date, time, repeat pattern, custom interval, weekday buttons, and the detected time zone](https://placehold.co/1200x675/284c67/ffffff.png?text=Recurring+campaign+schedule+editor)

## Adjust one session

On the campaign overview, a DM can manage the upcoming-session ledger:

- **Move** one generated session to a different date or time.
- **Cancel** one generated session.
- **Add** a one-off session with an optional label, such as “Finale.”
- Undo an exception to return to the normal schedule.

These changes affect only that occurrence; the repeating rule stays intact.

## Clear the schedule

Choose **Clear schedule** to remove future repeating sessions. One-off sessions remain, so remove those separately when needed.
