---
title: Join a campaign
description: Accept a shareable code, link, or private email invitation.
---

You must be signed in before you can join. Tablekeep shows an invitation preview before adding you to the campaign.

## Join with a code

1. Open **Campaigns** and choose **Enter a code**, or open **Join with a code** from the dashboard.
2. Enter the 10-letter-and-number code shared by the DM.
3. Review the campaign name and the role you will receive.
4. Accept the invitation.

![The join-by-code page with a ten-character code field and an invitation preview card](https://placehold.co/1200x675/40507d/ffffff.png?text=Join+with+code+and+campaign+preview)

You can also open the full invitation link. It takes you directly to the same preview.

## Accept a private email invitation

Open the invitation using the exact account it was sent to. If you are signed in with a different account, use **Switch account**, sign in as the invited address, and continue.

## When an invitation will not work

An invitation may be expired, revoked, already used, or tied to an archived campaign. A regenerated shareable code invalidates every copy of the earlier code immediately. Ask the DM for a new invitation if the preview says it is no longer available.
