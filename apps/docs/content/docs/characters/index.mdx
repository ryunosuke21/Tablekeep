Tablekeep separates who a character is from how that character exists in a particular campaign.

![The Characters page with active character cards, campaign counts, and a Recently deleted section](https://placehold.co/1200x675/46356a/ffffff.png?text=Character+folio+with+active+and+recently+deleted)

- The **identity** is player-owned and contains the character's name and bio.
- A **campaign sheet** contains that table's alias, ancestry, maximum HP, notes, class levels, backgrounds, conditions, inventory, and currencies.

This means the same character can play in more than one campaign without forcing every table to share the same mechanical state.
