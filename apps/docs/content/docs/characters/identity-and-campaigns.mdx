## Create a character

1. Open **Characters**.
2. Choose **Create a character**.
3. Enter a name and optional short bio.
4. Save the character.

The character appears in your Active list. You can create up to 20 characters.

![The new-character form with a character name, short bio, and create action](https://placehold.co/1200x675/56417a/ffffff.png?text=Create+a+character+identity)

## Edit the identity

Open the character from **Characters**. Under **Identity**, change the name or bio and choose **Save identity**. Both fields follow the character into every campaign. Renaming the character updates its page address.

## Start a campaign sheet

From the character page, find **Join a campaign**, select an active campaign you already belong to, and choose **Start a sheet**. You can also attach the character from that campaign's **Characters** section.

A character can have only one active sheet in a campaign, but can have separate sheets in several campaigns.

> Joining a campaign and bringing a character into it are separate actions. Accept the campaign invitation first, then start the sheet.
