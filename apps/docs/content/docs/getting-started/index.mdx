Tablekeep is designed to get out of the way once play begins. Set up your identity, then create a campaign, join one with a code, or make a character.

## A practical first session

1. Open Tablekeep and choose **Continue with Google**.
2. Add the name your table knows you by and, optionally, a profile picture.
3. If you are running the game, choose **Create a campaign**.
4. If you are joining a game, choose **Join with a code** and enter the code from your DM.
5. Create a character, then start a campaign sheet for the table where that character will play.

![The first-run path from the sign-in page through profile setup to the Tablekeep dashboard](https://placehold.co/1200x675/27305b/f8f7ff.png?text=Sign-in+to+profile+to+dashboard+flow)

> If you opened an invitation before signing in or before finishing your profile, Tablekeep returns you to that invitation afterward.

## Before you begin

You need an account to use campaigns, characters, and the rules wiki. Google sign-in is the currently usable sign-in method. The email sign-in control is visible in the app, but email delivery is not configured yet.
