title: Search, filter, and share wiki results
description: Narrow a complete category catalog instantly and keep the view in the URL.
---

Open any wiki category from the sidebar. Tablekeep loads the category once, then searches, filters, sorts, and groups the results in your browser.

## Search

Type in the search field. On a keyboard, press **/** when you are not already typing to jump to search. The result count updates as the query changes.

## Filter

Choose **Filters** to open category-specific facets. Each option shows a live count based on the other active filters. Select more than one option when you want a broader match, remove an active filter chip, or choose **Clear all**.

![A spell catalog with a search query, filter sheet, live result counts, source and level filters, and active filter chips](https://placehold.co/1200x675/364a70/ffffff.png?text=Wiki+search%2C+facets%2C+and+live+counts)

## Sort and change the view

Use the sort control to change result order. On wider screens, switch between the compact **List view** and visual **Card view**. Results may be grouped where that helps scan the category.

## Share the exact result set

Search, filters, sort order, and view are reflected in the page URL. Copy the browser address to share the same catalog setup with someone else.

> No source is selected by default. Add a source filter when your table wants to limit results to a particular reference document.
